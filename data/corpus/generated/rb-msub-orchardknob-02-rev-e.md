# 1.0 PURPOSE
Operate the unit safely and keep it available during declared events.
# 2.0 DATA
| Item | Value |
|---|---|
| Rating (MVA) | 20 |
| Primary / secondary (kV) | 115 / 23 |
| Set-up time, planning value (h) | 9 |
| Escort | State oversize permit required |
# 3.0 OPERATION
3.1 Request through TSO per DOM 14.170.
3.2 Survey pad, access and clearances before moving.
3.3 Ground the trailer and test before energising (TSO 06.130).
3.4 Energise only on an issued switching order (TSO 06.110).
CAUTION: Carbon monoxide. Never run a generator inside a building or near an air intake.
# 4.0 RECORDS
Run hours and fuel on F-WDS-207; defects to the maintenance work queue.
