1.0 PURPOSE

This procedure sets fuel monitoring and refuel requests for fixed standby generators at water
facilities.

2.0 SCOPE

It applies to diesel standby generators at SGW booster and pump stations in South Carolina and
Georgia. Covered units include GEN-PS38-COPPERLEAF and GEN-PS52-DEERWATER; the full list is in
Attachment A.

It does not apply to portable generators. For PS-17 see WDS 03.318; for monthly load tests see
WDS 03.350.

3.0 RESPONSIBILITIES

Water Incident Lead: approves refuel priority when several stations need fuel at once.

Station Operator: reads and logs fuel level, raises refuel requests.

Water SCADA Operator: watches remote tank-level signals and alerts the Station Operator.

Logistics Section Chief: assigns the vendor or the SGW fuel truck per MAL 05.040.

4.0 DEFINITIONS AND ABBREVIATIONS

Run time remaining: usable fuel divided by burn rate at current load.

Usable fuel: tank contents above the 10 percent pickup level.

5.0 PRECAUTIONS AND LIMITS

5.1 Never let a running unit fall below 25 percent tank. Below this level sediment pickup is
    likely.

5.2 Refuel request trigger: 60 percent tank.

5.3 Do not refuel a running unit from a vehicle without a bonding cable in place.

5.4 Use ultra-low sulfur No. 2 diesel only. From 1 November to 31 March request winter blend.

6.0 PROCEDURE

6.1 Start of Run

6.1.1 When a unit starts on loss of grid supply, record the start time and fuel level on
      F-WDS-207.

6.1.2 Report the start to the Water Incident Lead.

6.1.3 Calculate run time remaining using the Attachment A burn rate.

6.2 Monitoring

6.2.1 Read and log the fuel level every 4 h on F-WDS-207 while the generator runs.

6.2.2 Read the sight gauge, not only the SCADA signal. Record both if they differ by more than 5
      percent.

6.2.3 Log load (kW), oil pressure and coolant temperature with each fuel reading.

NOTE: At unmanned stations a roving operator may cover up to three stations. Keep the 4 h
      interval.

6.3 Refuel Request

6.3.1 When the fuel tank falls to 60 percent, raise a refuel request.

6.3.2 Submit the request on F-MAL-022 to the Logistics desk. State unit id, level, burn rate and
      route.

6.3.3 Flag any route that crosses a low-water crossing in GEP 2F.01 Attachment 2. Copperleaf
      Road (PS-38) and Deerwater Spur (PS-52) are on that list.

6.3.4 If run time remaining is shorter than the vendor delivery time, tell Logistics. Logistics
      then sends the SGW fuel truck first (MAL 05.040).

6.3.5 Log the delivery time and gallons received.

6.4 Shutdown

6.4.1 After return to grid supply, run unloaded for 5 min, then stop.

6.4.2 Top off to 95 percent within 24 h.

7.0 RECORDS

F-WDS-207 Generator Run Log; F-MAL-022 fuel request. Retain 5 years.
