# Station weather inputs (WP-22)

The `asos_*.csv` files are small extracts of routine hourly METAR observations from the Iowa Environmental
Mesonet ASOS archive (https://mesonet.agron.iastate.edu/request/download.phtml, accessed 2026-11-19), public
observations of the US National Weather Service and FAA. Stations: GSP (Greenville-Spartanburg), AGS (Augusta),
CAE (Columbia), CHS (Charleston), SAV (Savannah). Units: deg C, m/s, mm; times UTC.

Rebuild from the R05 download with
`uv run python -m sgw.generator.scenarios derive-weather --raw <asos_hourly_5stn_2023-01_2025-03.csv>`.
Every other file in this folder is generated by `uv run python -m sgw.generator.scenarios generate` and is
synthetic (alerts, rankings, hot spots, decisions); `manifest.json` lists the hashes.
