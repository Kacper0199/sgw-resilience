# Contracts

Python under `src/sgw/contracts/` is the source of truth. Everything in this folder, the TypeScript in
`web/src/contracts/*.gen.ts` and `data/fixtures/helene_micro/all.jsonl` is generated by `uv run sgw contracts`
(or `make contracts`) and committed. `make contracts-check` fails on any drift.

## Rules that the tests pin

- Every event carries `schema_version`; readers call `parse_event`, which upcasts through `UPCASTERS`.
- Probabilities and shares are integer ppm; `NaN` and infinities are rejected everywhere (`allow_inf_nan=False`,
  `CHECK` on `observation.value`).
- `action_hash = SHA-256(RFC 8785 JSON of {material, policy_version, tier})`. Material fields hold no floats, so
  Python and TypeScript produce the same bytes (`vectors/action_hash.json`).
- `decide_by = consequence - action lead time`; P10 <= P50 <= P90; the effective decide-by is never later than the
  case's own and propagates through an acyclic prerequisite graph (property tests in `tests/contracts/test_clocks.py`).
- Webhooks are signed as `SGW-Signature: t=<unix>,v1=<HMAC-SHA256(secret, "<t>.<id>.<body>")>` with a 300 s window.

## Fixture format (K9)

`data/fixtures/<scenario>/<feed>.jsonl`. Line 1 is a header (`fixture`, `schema_version`, `feed`, `feed_mode`,
`generator`, `generator_version`, `seed`, `calibration_source`, `scenario_window`, `licence`, `body_sha256`,
`hand_made`, `data_label`). Each following line is one K2 envelope, sorted by `event_time`; `body_sha256` covers
every byte after the header line. `helene_micro` is hand-made (the PS-17 story, synthetic values) and is the only
fixture that is not regenerated by `make data`.

## Change rule

After the W0 freeze only the maintainer changes a contract, additively (new optional field, enum value appended,
new endpoint), then runs `make contracts` and commits the regenerated files. A new enum value also needs a new
migration that replaces the domain's `CHECK`; `tests/contracts/test_db.py` compares the live domains with the enums.
